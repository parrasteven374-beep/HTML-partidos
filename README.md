# Interfaz Web - Gestión de Partidos

Frontend desarrollado con HTML5, CSS3 y JavaScript nativo para consumir y administrar la Web API de partidos de fútbol.

## Enlace en Producción
* Puedes acceder a la aplicación web en línea aquí: [https://parrasteven374-beep.github.io/HTML-partidos/](https://parrasteven374-beep.github.io/HTML-partidos/)

## Funcionalidades
* Configuración interactiva de la URL del servidor o API en la nube.
* Formulario de envío rápido de registros mediante peticiones HTTP POST asíncronas.
* Tabla dinámica sincronizada con el backend mediante peticiones HTTP GET.
